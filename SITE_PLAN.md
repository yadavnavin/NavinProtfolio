# Portfolio Site Plan

## Initial Scope

Build one exceptional homepage first.

Do not create many routes prematurely.

Potential future routes:

- `/`
- `/work/[project]`
- `/notes`
- `/about`

Only `/` is required for the first design phase.

---

## Homepage

### 01 — Navigation

Minimal.

Potential content:

- name / mark
- Work
- About
- Notes
- Contact
- theme control if eventually required

Navigation should have a distinctive but restrained interaction.

---

### 02 — Hero

Goal:

Immediately establish identity and visual direction.

Should communicate:

Software engineer
+
product builder
+
systems thinker

Do not use the conventional developer portfolio composition.

The hero may eventually contain the site's signature interaction.

---

### 03 — Selected Work

The primary portfolio section.

Major projects should appear as large editorial/cinematic stories rather than a grid of cards.

Initial candidates:

1. SeeMyUI
2. Multi-tenant platform
3. Workflow/form platform
4. Document platform

---

### 04 — Engineering Capabilities

Do not create a generic "Skills" logo wall.

Show what kinds of systems can be built:

Backend Systems
Interactive Products
Data
Real-time / Background Processing
Workflow / Automation
Developer Tools

Technologies can appear as supporting metadata.

---

### 05 — Engineering/System Visual

Potential interactive diagram connecting:

Interface
API
Services
Data
Async processing
AI

This section may become the signature visual.

Exact implementation TBD.

---

### 06 — Experiments / Open Source

Smaller explorations.

Different visual treatment from full case studies.

---

### 07 — About / Experience

Short.

Focus on engineering trajectory rather than biography.

---

### 08 — Notes

Optional initial section.

A few engineering ideas/articles rather than a complete blogging platform.

---

### 09 — Contact / Footer

Strong final composition.

Minimal links.

No generic contact form unless there is a concrete reason to have one.

---

## Phase 1

Only establish:

- global design system
- navigation
- hero

Do not build all sections at once.
